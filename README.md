# Skinner Box Configurations

Public evidence archive documenting institutional and technology-system friction, obstruction, lost time, financial effects, emotional cost, accessibility failures, and downstream consequences across organizations and platforms.

## Archive layout

- `incident-records/` — individual incident narratives and updates
- `timeline/` — chronological summaries
- `correspondence/` — exported or transcribed communications
- `message-exports/` — working copies of device-message exports
- `screenshots-redacted/` — publication-ready images
- `technical-notes/` — technical findings and attribution notes
- `evidence-index.csv` — evidence catalog

## Evidence handling

Original exports should be retained separately without modification. Files in this repository are public working copies intended for organization, analysis, and publication. Each entry should identify its source, date, organization, and whether redaction or transformation occurred.
