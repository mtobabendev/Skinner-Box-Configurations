# Skinner Box Configurations

Public evidence archive operating under the **With Extra Steps Protocol** and documenting institutional and technology-system friction, obstruction, lost time, financial effects, emotional cost, accessibility failures, and downstream consequences across organizations and platforms.

## Archive layout

- `incident-records/` — individual incident narratives and updates
- `timeline/` — chronological summaries
- `correspondence/` — exported or transcribed communications
- `message-exports/` — working copies of device-message exports
- `screenshots/` — supplied image evidence
- `technical-notes/` — technical findings and attribution notes
- `evidence-index.csv` — evidence catalog
- `WITH-EXTRA-STEPS-PROTOCOL.md` — definition and measurement rules
- `chatgpt-intervention-log.csv` — every ChatGPT withholding, redaction, refusal, correction cycle, and resulting time cost

## Publication instruction

Preserve the owner's supplied wording, profanity, names, accusations, screenshots, and evidence uncensored unless the owner explicitly instructs otherwise.

If ChatGPT withholds, redacts, summarizes, transforms, or refuses any supplied material, ChatGPT must:

1. Identify exactly what was changed or withheld.
2. State the reason.
3. Record the intervention in `chatgpt-intervention-log.csv`.
4. Record the correction cycle, extra steps, and measurable or estimated time cost.
5. Tell the owner so the owner can decide whether to upload a different version personally.

## Evidence handling

Original exports should be retained separately without modification. Files in this repository are public working copies intended for organization, analysis, and publication. Each entry should identify its source, date, organization, and whether any redaction or transformation occurred.
