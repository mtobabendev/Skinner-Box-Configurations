## Counting rules

1. Record each distinct block of active work, forced interruption, rework, or other measurable loss as its own line item.
2. Calculate amount as `minutes ÷ 60 × hourly rate`.
3. Keep estimates, lockout windows, and opportunity-cost claims outside the confirmed subtotal until supported and checked for overlap.
4. Preserve the source for every start time, end time, duration, and rate.
5. Reconcile historical entries against accounting records before treating them as confirmed.
6. Do not count the same minute in more than one confirmed line item.
